**TASK MANAGER**

A modern desktop Task Manager application built with Java and JavaFX. The application helps users create, organize, and track their tasks with support for priorities, categories, due dates, and task completion.

**Features**

* Create, edit and delete tasks
* Mark tasks as completed
* Search tasks by title, description, category, or priority
* Organize tasks using categories and priorities
* Set due dates for tasks
* Save tasks locally and automatically load them on startup
* English and German language support
* Modern and responsive JavaFX user interface

**Technologies Used**

* Java
* JavaFX
* CSS
* Object-Oriented Programming (OOP)
* File I/O for data persistence
* Git and GitHub

**How to Run**
1. Clone the repository:
   git clone https://github.com/YourUsername/TaskManager.git
2. Open the project in your IDE.
3. Run Main.java
